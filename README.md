# UX-Reloop-Mobile
Reloop adalah rancangan aplikasi mobile recommerce khusus barang preloved yang menyediakan dua mode transaksi terintegrasi, yaitu jual dan sewa. Aplikasi ini dirancang untuk mengatasi masalah asymmetric information (ketimpangan informasi antara penjual dan pembeli) serta mendukung penerapan prinsip circular economy di tengah masyarakat.
